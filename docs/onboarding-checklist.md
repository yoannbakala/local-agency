# Client Onboarding Checklist

## After Deposit Received

- [ ] Send welcome email with next steps
- [ ] Send content request list (see below)
- [ ] Create project folder for this client
- [ ] Copy roofing template (or appropriate niche template)
- [ ] Update `site.config.ts` with client info
- [ ] Set internal deadline (target: 7 days from deposit)

## Content Request — Send to Client

> Hi [Name],
>
> Thanks for choosing us! To get started on your website, we need a few things:
>
> 1. **Your logo** (any format — PNG, JPG, PDF, or even a photo of it)
> 2. **Photos** of your work, team, trucks, or equipment (phone photos are great)
> 3. **List of services** you want on the website
> 4. **Service areas** (cities/neighborhoods you serve)
> 5. **Business hours**
> 6. **Any specific wording** you want included (tagline, about us, etc.)
> 7. **Google Business Profile** login (optional — so we can connect your site)
>
> Don't overthink it — send what you have. We'll make it look great.
>
> We'll have a homepage draft ready for you within 2-3 days.

## Content Received — Build Phase

- [ ] Logo received (or using text logo)
- [ ] Photos received (or using professional stock)
- [ ] Services confirmed
- [ ] Service areas confirmed
- [ ] Phone / email / address confirmed
- [ ] Any special requests noted
- [ ] Customize template with client content
- [ ] Build all pages
- [ ] Test on mobile
- [ ] Test all links and forms
- [ ] Send draft to client for review

## Revision Phase

- [ ] Client feedback received
- [ ] Revision 1 complete
- [ ] Client feedback on revision 1
- [ ] Revision 2 complete (if needed)
- [ ] Client approval received
- [ ] Final payment received
