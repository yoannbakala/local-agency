# Website Launch Checklist

## Pre-Launch — Content & Design
- [ ] All pages complete and reviewed
- [ ] All text proofread (business name, phone, address — triple-check)
- [ ] All links working (nav, footer, CTAs, phone, email)
- [ ] Contact form submits correctly and sends notification
- [ ] Images optimized (compressed, proper dimensions)
- [ ] Mobile layout tested on real phone
- [ ] Tablet layout tested
- [ ] Desktop layout tested
- [ ] Client has approved the final version
- [ ] Final payment received

## Pre-Launch — Technical
- [ ] Domain connected and resolving
- [ ] SSL certificate active (https://)
- [ ] Favicon set
- [ ] Page titles and meta descriptions set for every page
- [ ] Open Graph tags set (for social sharing)
- [ ] 404 page exists or handled gracefully
- [ ] Site loads in under 3 seconds
- [ ] No console errors
- [ ] No broken images

## Launch
- [ ] Deploy to production
- [ ] Verify site loads on domain
- [ ] Verify SSL is active
- [ ] Test contact form on live site
- [ ] Test click-to-call on mobile
- [ ] Test on Chrome, Safari, Firefox (at minimum)

## Post-Launch — Analytics & SEO
- [ ] Google Analytics installed and tracking
- [ ] Google Search Console set up and sitemap submitted
- [ ] Site submitted to Google for indexing
- [ ] Google Business Profile updated with correct website URL
- [ ] Verify business name, address, phone match across Google/Yelp/Facebook/site

## Post-Launch — Client Communication
- [ ] Send launch confirmation email to client
- [ ] Walk client through the live site
- [ ] Explain how to request edits
- [ ] Discuss maintenance plan (if offered)
- [ ] Ask for testimonial / review
- [ ] Ask for referrals
- [ ] Schedule 30-day check-in
